Корпоративный сайт и единая авторизация Wilo ID

Управляемый корпоративный сайт Wilo в России и Wilo ID для единого входа в продукты компании.

МОЯ РОЛЬProject Manager
КОМАНДА5 человек
КОМПАНИЯDD Planet

Задача

Российскому подразделению требовался корпоративный сайт, который можно развивать и наполнять силами контентной команды. Отдельная задача — единый вход в продукты через Wilo ID.

Мой вклад

  • Руководил командой из 5 человек в проектах корпоративного сайта и Wilo ID.
  • Координировал требования, реализацию и согласование результатов с заказчиком.

Как устроено решение

Управляемый сайт

Strapi хранит контент и структуру блоков; Next.js отвечает за отображение. Редактор собирает страницы, обновляет материалы и работает с каталогом без отдельной задачи разработчику.

Каталог и Wilo ID

Данные о продукции поступают из внутренней системы заказчика. Wilo ID обеспечивает единую авторизацию в продуктах компании.

Результаты проекта

  • Контентная команда получила инструмент для самостоятельного обновления сайта.
  • Каталог связан с внутренней системой заказчика.
  • Единая авторизация объединяет доступ к продуктам Wilo.
  • Проект остался с компанией на поддержке.
